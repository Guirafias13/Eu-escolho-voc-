# Rango Certo
<br>
O Rango Certo e um aplicativo web interativo desenvolvido para simplificar a decisao alimentar diaria.
<br>
O sistema permite que o usuario filtre receitas de forma inteligente com base em seus objetivos, restricoes alimentares e tempo disponivel.
<br>
Ele gera um menu personalizado e constroi automaticamente uma lista de compras unificada e otimizada para o supermercado.
<br>
## Funcionalidades Principais
<br>
* Filtro Estrito de Preferencias: Busca receitas cruzando dados de estilo alimentar, nivel de habilidade e tempo de preparo.
<br>
* Gerenciamento de Alergias: Sistema inteligente que exclui automaticamente pratos que contenham ingredientes marcados como restricoes pelo usuario.
<br>
* Menu por Refeicao: Gera um cardapio focado estritamente nas refeicoes selecionadas (Cafe da Manha, Almoco, Lanche ou Jantar).
<br>
* Sorteio Dinamico: O algoritmo rotaciona os pratos de forma aleatoria a cada busca com base em um banco de dados interno de 60 receitas.
<br>
* Visualizacao Detalhada em Modal: Exibe ingredientes e modo de preparo in uma janela flutuante moderna com efeito de desfoque de fundo e rolagem isolada.
<br>
* Lista de Compras Inteligente: Agrupa ingredientes semelhantes por palavras-chave e contabiliza a repeticao dos itens para evitar redundancias.
<br>
* Reset de Interface: Botao funcional para limpar os resultados exibidos e redefinir o formulario simultaneamente.
<br>
## Tecnologias Utilizadas
<br>
* HTML5: Estruturacao semantica dos formularios, seletores e areas de injecao de conteudo.
<br>
* CSS3: Estilizacao modular, uso de variaveis globais, sombras em camadas tridimensionais, efeito Glassmorphism e fundo geometrico personalizado.
<br>
* JavaScript (ES6+): Manipulacao do DOM, lacos de repeticao para processamento de listas, arrays relacionais e controle de fluxo do navegador.
<br>
## Estrutura do Projeto
<br>
* index.html: Contem o esqueleto da aplicacao, incluindo o formulario de preferencias e o container de resultados.
<br>
* style.css: Arquivo responsavel por toda a identidade visual, tipografia combinada e design responsivo.
<br>
* script.js: Centraliza a logica de negocio, o banco de dados de receitas e os motores de filtragem e construcao de interface.
<br>
## Como Executar o Projeto
<br>
1. Baixe os arquivos do projeto para o seu computador.
<br>
2. Certifique-se de que os tres arquivos (index.html, style.css e script.js) estao salvos juntos no mesmo diretorio.
<br>
3. Abra o arquivo index.html em qualquer navegador web moderno.
<br>
4. Utilize o atalho Ctrl + F5 (ou Cmd + Shift + R no Mac) para garantir a limpeza do cache durante os testes.
